# 문서 색인 (index)

살림풍경 MD팀 인수인계 자료 전체 목록. 원본 38개 + `CLAUDE.md` + `wiki/` 12개
(문서 10 + 대시보드 데이터 `data/dashboard.json` + 검산 스크립트 `data/_verify.py`).

이 위키가 처음이라면 [README.md](README.md)부터 — 어디서부터 볼지와 정리 규칙 요약이 있다.

- 이 문서는 **위키 산출물**이다. 원본이 아니므로 여기 적힌 값을 근거로 인용하지 말고,
  반드시 `출처` 칸의 원본 파일을 열어 확인할 것.
- `작성일`은 **파일 내부에 적힌 날짜**만 적었다. 파일 생성·수정 시각은 재다운로드·복사 때
  바뀌므로 근거로 쓰지 않는다.
- 문서에 날짜가 없으면 `미상`. 추정은 `(추정, 근거: 파일명)`으로 사실과 구분했다.
- 거래처는 `거래처/회사명.md`에 한 회사씩 모았다. 파일명에 상태를 넣지 않으므로,
  기존 거래처인지 후보인지 종료인지는 각 문서 안에서 확인할 것(`CLAUDE.md` 위키 규칙 3번).
- 각 위키 문서의 값에는 `[확정]`·`[모름]`·`[충돌]`이 붙어 있다(`CLAUDE.md` 위키 규칙 5번).
  `[확정]`이라도 **근거가 1건인지 5건인지는 `근거` 칸을 봐야 한다.**
- 갱신: 2026-10-08 (작성: Claude Code, 근거: 저장소 전수 조사)

`반품교환프로세스.md`의 7일은 **인용하지 말 것.** 원본은 사실 기록이므로 고치지 않는다.

  필요하다고 남겼다. 원본은 고치지 않는다 — 재계산은 원 담당자 몫이다.

# 대시보드

살림풍경 인수인계 아카이브 대시보드 — 분포·관계·타임라인 위젯 3개. Next.js(App Router) + React.

```bash
cd dashboard
npm install
npm run dev      # http://localhost:3000
```

## 데이터는 어디서 오나

`wiki/data/dashboard.json`을 **런타임에 그대로 읽는다**(`app/page.jsx`의 `fs.readFileSync`).

`dashboard/` 안에 JSON 사본을 두지 않았다. 사본을 두면 원본이 바뀔 때 화면이 조용히
낡는데, 이 저장소가 단가표 4벌·CS매뉴얼 4벌로 겪은 문제가 정확히 그것이다.
JSON을 고치고 브라우저를 새로고침하면 바로 반영된다(`dynamic = 'force-dynamic'`).

경로가 상대 경로라 **`dashboard/` 안에서 실행해야 한다.** 다른 곳에서 띄우면
"데이터를 읽지 못했다" 화면이 파일 경로와 함께 뜬다.

## 지금 있는 것

**위젯 1 — 카테고리별 문서 분포**

- **스탯 타일 3개** — 원본 38 / wiki 12 / 합계 51
- **가로 막대 차트** — 폴더 10개. 원본(읽기 전용) 9개와 파생(쓰기 가능) 1개를
  나눠 보여주되 **가로 눈금은 공유**해서 길이를 그대로 비교할 수 있다
- **행 hover·포커스 툴팁** — 그 폴더의 성격과 주의사항(`role`·`trust`)
- **표 보기 토글** — 차트와 같은 값을 경로·성격·주의까지 붙여서

**위젯 2 — 문서 간 관계** (엣지 36건 · 유형 13종)

- **필터 한 줄** — 유형 칩 13개 + "주의만" 토글. 아래 차트와 목록을 함께 좁힌다
- **유형별 건수 막대** — 막대를 눌러도 필터가 걸리고, 선택하면 나머지가 흐려진다
- **관계 목록** — 유형별로 묶어 `from → to`, 관계의 뜻, 근거 문서까지.
  `warning`이 붙은 4건은 ▲ 주의 배지, 해소된 값 충돌 1건은 "해소됨" 배지

**위젯 3 — 시간축 타임라인** (이벤트 32건 · 2024-08-01 ~ 2027-02-28)

- **필터 한 줄** — 전체 / 오늘까지 29 / 오늘 이후 3 + "주의만" 토글
- **분기별 이벤트 수 세로 막대** — 11분기 연속. **이벤트가 없는 분기도 빈 자리로 남긴다**
  (건너뛰면 축이 압축돼 "2025년 하반기에 아무 기록도 없다"가 지워진다).
  전부 오늘 이후인 분기는 막대를 비우고, 오늘이 낀 분기에는 ▲ 표시
- **연대순 이벤트 목록** — 연도별로 묶고, 오늘 이후로 넘어가는 지점에 구분선.
  `날짜 추정` · `미결` · `오늘 이후` · ▲ 주의 배지

**공통** — 다크 모드는 OS 설정을 따르고 ◐ 버튼으로 뒤집는다.

### 타임라인은 정렬하지 않는다

`timeline` 배열의 **순서가 곧 표시 순서**다. 날짜 문자열로 다시 정렬하면
`2026-09`(9월 말 이동)처럼 월 단위로만 적힌 항목이 `2026-09-05`보다 앞으로 튄다.
없는 날짜를 `2026-09-30`으로 채워 정렬을 맞추는 건 이 저장소가 금지한다 —
추측한 날짜가 다시 근거 행세를 하기 때문이다(`_meta.timeline_order`).

### 왜 노드-링크 그래프가 아닌가

관계를 그래프로 그리고 싶어지지만, 여기서는 목록이 더 정확하다.

- 노드가 50개인데 라벨이 한글 파일명이라 서로 겹쳐 읽히지 않는다
- 의미를 지닌 분류가 13종이다 — 7종을 넘으면 색으로는 구분이 안 돼 표가 낫다
- 이 데이터에서 실제로 궁금한 건 "무엇이 무엇을 대체했나 / 근거가 몇 건인가"이지
  전체 위상이 아니다. 그건 필터되는 목록이 바로 답한다

## 차트 규칙

- **단일 계열이므로 색은 하나다.** 막대마다 다른 색을 주거나 값이 클수록 진하게
  칠하지 않았다 — 막대 길이가 이미 값을 말하는데 색까지 같은 값을 나타내면
  유일하게 남은 채널을 낭비하는 것이다(value-ramp on nominal categories 안티패턴).
- 팔레트는 눈으로 고르지 않고 **검증기를 돌렸다.**
  `#2a78d6`(light) / `#3987e5`(dark) 모두 lightness band · chroma floor ·
  대비 3:1 전 항목 PASS.
- 계열이 하나라 **범례를 두지 않았다.** 제목이 무엇을 그린 것인지 말한다.
- 막대는 14px(상한 24px), 데이터 끝만 4px 라운드·베이스라인 쪽은 각짐.
  눈금선은 실선 헤어라인이고 마크에 테두리를 두르지 않았다.
- **툴팁이 값을 가두지 않는다.** 값은 막대 끝에 직접 붙어 있고, 표 보기에도 있다.
  키보드 포커스로도 툴팁이 뜨고, 히트 영역은 행 전체(34px)다.
- **상태색(주의)은 예약 토큰이고 계열색으로 쓰지 않는다.** ▲ 글리프에만 색이 들어가고
  "주의"라는 글자는 텍스트 토큰을 유지한다 — 색만으로 뜻을 전달하지 않기 위해서다.
- **관계 유형 이름은 화면에 박지 않았다.** `_meta.relation_types`의 설명을 그대로
  읽어 쓴다. 코드에 한글 이름을 복사해 두면 JSON이 바뀔 때 화면만 옛말을 한다.

## 값을 인용할 때

이 화면의 숫자는 **근거가 아니다.** `wiki/data/dashboard.json`은 위키 산출물이고,
위키는 찾는 곳이지 확인하는 곳이 아니다. 단가·기간·재고·매출을 인용할 때는 해당
폴더의 원본을 열어 출처 파일명과 작성일을 함께 밝힐 것 — 저장소 규칙은
`CLAUDE.md`의 "작업 시 지켜야 할 것"에 있다.

## 테스트

```bash
cd dashboard
npx playwright install chromium   # 처음 한 번 — E2E 테스트용 브라우저
npm test           # SSR 스모크 19 + E2E 32 = 51건
npm run test:ssr   # 브라우저 없이 (빠름)
npm run test:e2e   # Playwright chromium
```

두 층으로 나눠 뒀다. 둘 다 `tests/`에 있다.

**1. SSR 스모크 — `tests/render.node.test.mjs` (19건, 약 1.8초)**

dev 서버를 띄워(포트 3599, `TEST_PORT`) `/`를 한 번 받고 HTML을 검사한다.
의존성 없이 `node:test` + 내장 `fetch`만 쓴다. 브라우저가 없는 환경에서도 돈다.

**2. E2E — Playwright chromium (32건, 약 8초)**

`playwright.config.mjs`가 dev 서버를 띄우고(포트 3601, `E2E_PORT`) 내린다.
`tests/*.spec.mjs`만 집어가므로 위 node 테스트와 섞이지 않는다.

| 파일 | 보는 것 |
|---|---|
| `render.spec.mjs` | 세 위젯이 **실제로 보이는지**(visible), 개수·값이 데이터와 일치 |
| `interaction.spec.mjs` | 표 보기 토글, hover·키보드 툴팁, 유형 칩·막대 필터, 주의만, 타임라인 범위 필터, 테마 전환이 배경색을 실제로 바꾸는지 |
| `layout.spec.mjs` | 라벨 잘림, 막대가 값에 비례하는지, 막대가 트랙을 넘는지, 카드 밖으로 삐져나오는 요소, 가로 스크롤(1000px·420px), 스크린샷 |

`screenshots/`에 전체·위젯별 라이트/다크 8장이 떨어진다(gitignore).

### 기대값을 테스트에 박지 않았다

`tests/_data.mjs`가 `wiki/data/dashboard.json`을 읽어 카테고리 수·엣지 수·유형별
건수·이벤트 수·warning 건수를 도출한다. 숫자를 박아 두면 데이터가 바뀔 때 테스트만
옛말을 하게 되는데, 이 저장소가 파일명 `최종`으로 겪은 문제와 같은 종류다.

### 깨지는지 확인했다

SSR 테스트는 타임라인 위젯을 실제로 떼어내고 돌려 봤다. 처음엔 17/18이 깨졌는데
— 구간 분할이 위젯 부재 시 즉시 단정을 던져 무관한 위젯까지 전부 실패시켰다 —
위젯별 가드를 넣어 **페이지 2건 + 타임라인 6건만** 깨지도록 고쳤다.

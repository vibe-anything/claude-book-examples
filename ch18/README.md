## 쓰는 법

`part3-work-folder/`를 통째로 작업할 자리로 복사한다. Git은 `git init` 후 시작 커밋 하나로 출발
(ch17 README 참조).

**전제**: 17장 §17.8의 MarkItDown MCP 연결이 돼 있어야 워드 파일까지 검색된다.
이 연결은 명령을 입력한 폴더에만 등록된다. 안 돼 있다면 터미널에서 작업할 자리에 복사한
`part3-work-folder/`로 먼저 이동한 뒤 아래 명령을 실행한다. uv가 없어도 등록은 오류 없이 끝나지만
연결은 실패한다. 먼저 `uvx --version`으로 버전이 나오는지 확인한다(안 나오면 17장 §17.8의 uv 설치부터).

```bash
claude mcp add markitdown -- uvx markitdown-mcp
```

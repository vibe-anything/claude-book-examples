책의 실습을 따라 하다가 막히거나, 중간 장부터 시작하고 싶을 때 쓰는 저장소입니다.

## 이렇게 쓰세요

`chNN/` 폴더에는 그 장을 **시작할 때** 있어야 하는 파일이 들어 있습니다. 7장부터 읽는다면 `ch07/`을 받으면 됩니다. 앞 장을 따라 하며 만든 폴더가 있다면 그 폴더로 이어 가셔도 됩니다.

받는 방법은 두 가지예요.

- Git을 쓴다면 `git clone https://github.com/vibe-anything/claude-book-examples.git`
- Git이 없다면 이 페이지의 [Code]-[Download ZIP]

## 폴더 안내

| 부 | 폴더 | 들어 있는 것 |
| --- | --- | --- |
| 1부 | `ch03/` | 3장에서 정리할 회의 메모(`notes.txt`) |
| 2부 | `ch06/` ~ `ch12/` | 투자 브리핑 비서를 만드는 각 장의 시작 상태 |
| 2부 | `final/` | 12장까지 마친 완성본(13장 시작 상태) |
| 3부 | `ch15/` ~ `ch20/` | 정리할 업무 폴더(`part3-work-folder/`)의 각 장 시작 상태 |
| 부록 | `appendix/` | 부록 실습에서 입력할 글 모음(받을 실습 파일은 없음) |

1·2·4·5장은 따로 받을 폴더가 없습니다. 새 폴더에서 시작하거나 앞 장의 결과를 이어 쓰기 때문이에요. 13장을 12장 없이 시작한다면 `final/`을 받아 12장처럼 Vercel 공개 URL까지 맞춘 뒤 시작하세요. 14장에서 둘러보는 폴더는 `ch15/`에 있습니다.

## 알아 두면 좋아요

- 장 폴더에는 Git 기록이 들어 있지 않아요. 2부를 8장 이후부터 시작한다면 받은 폴더를 이 저장소 밖 작업할 자리로 복사한 뒤, Claude Code에 “이 폴더를 Git 저장소로 만들고 지금 상태를 커밋해 줘.”라고 요청하세요. 이때 Git이 이름과 이메일을 물으면 “이 저장소에만 이름과 이메일을 설정해 줘.”라고 답하면 됩니다(7장 TIP). 12장 배포 전에는 7장처럼 GitHub에도 올려 주세요.
- API 키 같은 비밀값은 들어 있지 않습니다. 11장부터는 Claude Code에 “.env.example을 복사해서 .env 파일을 만들어 줘.”라고 요청한 뒤, 10장처럼 `.env`를 메모장이나 텍스트 편집기로 열어 NAVER API HUB 키를 넣고 저장해 주세요. 메모장은 저장하지 않은 채 창을 닫아도 묻지 않을 수 있어요.
- 대시보드가 든 폴더(`ch10/` ~ `ch12/`, `final/`, `ch20/part3-work-folder/dashboard/`)는 처음 실행하기 전에 Claude Code에 “이 폴더에서 npm install을 실행해 줘.”라고 요청하세요. Node.js가 없으면 설치 방법도 함께 알려 줍니다. 10장부터 시작한다면 “대시보드를 띄우고 여는 주소를 알려 줘.”라고도 요청해 두세요.
- 3부를 18장 이후부터 시작한다면 17장의 MarkItDown 연결을 먼저 해 주세요.
- 3부 장 폴더의 실습 폴더는 이름이 모두 `part3-work-folder/`예요. 쓰던 폴더가 작업할 자리에 있다면 터미널 창을 닫고 그 폴더 이름을 바꿔 둔 뒤 복사하세요. 그대로 복사하면 Windows는 두 폴더를 하나로 합쳐 앞 장의 파일이 섞입니다.
- 결과가 이 저장소와 조금 달라도 괜찮습니다. AI는 같은 요청에도 매번 조금씩 다르게 답하니까요. 내용이 맞으면 성공입니다!

# 부록 「마음을 전하는 18초」

부록에는 받아야 할 실습 파일이 없습니다. 필요한 파일과 도구는 Claude Code와 대화하며 준비해요.

이 폴더에는 책의 ‘Claude Code에 입력’ 상자 글을 그대로 모아 두었습니다. 종이책을 보며 옮겨 적기 번거로우면 여기서 복사해 입력창에 붙여 넣으세요.

## 시작하기 전에

- Claude Code 설치와 로그인을 마친 상태에서 시작합니다.
- 초대장은 `my-invitation`, 할 일 영상은 `my-day` 폴더에서 만듭니다. 폴더를 만든 뒤 그 폴더에서 Claude Code를 열고 모델을 Opus로 고르세요.
- Node.js 같은 실행 도구가 없다고 나오면 Claude Code가 설치 방법을 알려 줍니다. 설치해도 되는지 물으면 내용을 읽고 진행하세요. 암호는 Claude Code에 알려 주지 말고 설치 창이나 터미널에 직접 입력합니다.
- 여러 줄짜리 글은 한 번에 붙여 넣으세요. 한 줄씩 치다가 Enter를 누르면 첫 줄만 먼저 보내집니다.

## 초대장 만들기(`my-invitation`, HyperFrames)

### A.1 봉투 안에 초대장 담기

```text
HyperFrames로 18초짜리 세로 초대장 영상을 만들어 줘.
모임 이름은 “책 한 권, 커피 한 잔”이야.
0~4초: “이번 토요일, 잠깐 비워 둘래?”와 봉투를 보여 줘.
4~9초: 봉투가 열리고 초대장, 책, 커피잔이 나오게 해 줘.
9~13초: “토요일 오후 3시”, “동네 책방”, “좋은 문장 하나만 가져와”를 보여 줘.
13~18초: “책 한 권, 너만 오면 돼.”로 마무리해 줘.
따뜻한 종이 색에 산호색을 쓰고, 글자는 크게 해 줘.
사진과 음악 없이 만들고 “가상 모임”임을 작게 표시해 줘.
이 폴더에 파일을 만들고 필요한 도구와 공식 제작 Skill을 준비해 줘.
설치할 내용을 설명하고, 미리 보기를 실행한 후 웹 브라우저에서 접속할 주소를 알려 줘.
```

### A.2 시간과 장소가 너무 빨리 지나갈 때

시간과 장소가 이미 잘 읽힌다면 건너뜁니다.

```text
모임 시간과 장소를 조금 더 오래 보여 줘.
글자는 휴대전화에서도 읽기 쉽게 해 줘.
다른 장면과 전체 길이 18초는 유지해 줘.
```

### A.3 초대의 말을 내 말투로 바꾸기

```text
수정 전 원본을 따로 보관해 줘.
마지막 문구를 “책 한 권, 너만 오면 돼.”에서 “좋은 문장, 함께 나눠요.”로 바꿔 줘.
첫 줄은 “좋은 문장,”, 둘째 줄은 “함께 나눠요.”로 해 줘.
글자가 잘리면 크기와 줄 바꿈만 조절해 줘.
다른 장면과 색, 움직임은 그대로 둬.
```

### A.4 친구에게 보낼 파일 만들기

```text
지금 초대장을 out/invitation-v1.mp4로 저장해 줘.
같은 이름이 있으면 새 번호를 붙여 줘.
휴대전화에서 볼 수 있는 세로형 MP4로 만들어 줘.
18초 길이와 마지막 문구를 확인하고 파일 위치를 알려 줘.
저장이 안 되면 이유와 다음에 할 일을 알려 줘.
```

## 나를 위한 영상(`my-day`, Remotion)

`my-day` 폴더를 만들고 그 폴더에서 Claude Code를 새로 연 뒤 시작합니다. 초대장은 `my-invitation` 폴더에 그대로 두세요.

### A.5 이번에는 나를 위한 영상 만들기

```text
Remotion으로 “오늘 할 일, 딱 세 개” 영상을 만들어 줘.
18초 세로 영상이고, 사진과 음악은 쓰지 않을 거야.
0~3초: “오늘 뭐부터 하지?”를 크게 보여 줘.
3~7초: “메일 답장”, “산책 10분”, “책 5쪽” 카드를 흩어 놓아 줘.
7~13초: 카드 세 개가 차례로 모여 가지런히 놓이게 해 줘.
13~18초: “오늘도 하나씩.”으로 마무리해 줘.
어두운 배경에 흰 글자와 따뜻한 주황색을 써 줘.
이 폴더에 필요한 파일과 도구를 준비해 줘.
미리 보기를 실행하고 브라우저에서 접속할 주소와 영상 이름을 알려 줘.
```

### A.6 움직임을 조금 더 다듬어 보고 싶다면(선택)

```text
카드가 한꺼번에 도착한다면 움직임을 조금 더 차분하게 바꿔 줘.
카드 세 개가 한 장씩 차례로 모이고, 제자리에 놓이면 멈추게 해 줘.
문구와 색, 전체 길이는 유지해 줘.
```

### A.7 나를 재촉하지 않는 한 문장

```text
수정 전 원본을 따로 보관해 줘.
마지막 문구를 “오늘도 하나씩.”에서 “오늘은 이 세 개만.”으로 바꿔 줘.
다른 문구와 카드 움직임은 그대로 둬.
수정 전후 영상의 15초 시점 화면을 PNG로 저장해 줘.
두 이미지의 위치를 알려 줘.
```

### A.8 내 하루를 저장하기

```text
지금 영상을 out/my-day-v1.mp4로 저장해 줘.
같은 이름이 있으면 새 번호를 붙여 줘.
18초짜리 세로형 MP4로 만들고 파일 위치를 알려 줘.
마지막 문구가 “오늘은 이 세 개만.”인지 확인해 줘.
```

### 내일은 다른 세 가지(응용)

```text
지금 영상은 보관하고 복사본을 만들어 줘.
카드 세 장의 문구를 “늦잠”, “산책”, “좋아하는 영화”로 바꿔 줘.
첫 질문은 “쉬는 날, 뭐부터 할까?”로,
마지막은 “오늘은 느긋하게.”로 바꿔 줘.
글자가 잘리는 곳만 조절하고 다른 움직임은 유지해 줘.
```

## A.9 다음 영상은 누구에게 보낼까요?

`my-invitation` 폴더에서 Claude Code를 다시 열고 시작합니다.

```text
독서 모임 초대장은 보관하고 새 폴더에 복사본을 만들어 줘.
봉투가 열리면 “오늘의 주인공에게”가 나오게 해 줘.
모임 시간과 장소는 빼고 “좋아하는 일로 가득한 하루”를 넣어 줘.
마지막은 “네 하루를 응원해!”로 마무리해 줘.
미리 보기를 켜고 새 폴더의 위치를 알려 줘.
```

## 알아 두면 좋아요

- 미리 보기 주소(localhost가 들어간 주소)는 내 컴퓨터에서만 열립니다. 다른 사람에게는 저장한 MP4 파일을 보내세요.
- 영상을 보는 동안 미리 보기를 실행 중인 창은 닫지 마세요. 주소가 열리지 않으면 화면에 나온 오류를 Claude Code에 보여 주세요.
- 결과가 책의 그림과 색이나 움직임이 조금 달라도 괜찮아요. 같은 요청에도 매번 조금씩 다르게 만들어집니다.

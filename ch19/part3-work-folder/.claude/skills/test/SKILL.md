위키(wiki/)에 적힌 값들이 원본(raw) 문서와 일치하는지 자동 대조한다.

절차:
1. wiki/ 안의 사실 값(단가, 날짜, 기간, 수량, 담당자)을 추려낸다.
2. 각 값을 원본 문서에서 재확인한다.
3. 결과를 [확정]/[모름]/[충돌] 태그와 근거 문서명으로 보고한다. 충돌이 하나라도
   있으면 "사람이 확인할 목록"으로 맨 위에 정리한다.
4. 지어내지 않는다. 원본에 없는 값은 [모름]으로 둔다.

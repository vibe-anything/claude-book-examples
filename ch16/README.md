# ch16 — 16장을 시작할 때 있어야 하는 것

15장을 마친 상태다. 정리 전 업무 폴더(8개 폴더, 38개 파일)에 `/init`으로 만든
`CLAUDE.md`가 더해져 있다. 실제 Claude Code 세션의 `/init` 실행 결과를 바탕으로 했고,
진실 공급원·알려진 불일치·확인 필요 목록에 15장 끝의 중복·버전 갈림 조사까지
병합돼 있다. 본문 흐름에 맞춰 대성물산 단가 판정은 "확인 필요"로 남겼다.

## 쓰는 법

`part3-work-folder/`를 통째로 작업할 자리로 복사하고 16장을 시작한다. 아직 Git 저장소가 아니다 —
`git init`과 "정리 전 상태" 커밋은 16장 본문에서 직접 한다.

여러분이 15장을 직접 따라왔다면 그 폴더를 그대로 쓰면 된다. CLAUDE.md의 구성과
문구가 이 스냅샷과 똑같을 필요는 없다 — 폴더 구조가 요약돼 있고 확인할 항목이
적혀 있으면 정상이다.

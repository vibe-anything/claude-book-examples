# ch17 — 17장을 시작할 때 있어야 하는 것

16장을 마친 상태다. 15장 결과에 더해:

- 대성물산 단가표가 작성일 기준 이름으로 정리됨
  (`거래처/대성물산/단가표/2026-01-10.csv` · `2026-04-03.csv` · `2026-06-15.csv`)
- 내용이 같던 사본 2개(대성물산 폴더의 `- 복사본`, 회의록 폴더에 잘못 저장돼 있던
  것)는 원래 이름 그대로 `거래처/대성물산/_보관/`으로 이동 — 지우는 대신 보관한다는 규칙의 결과
- `CLAUDE.md`에 정리 규칙 3줄(작성일 기준 이름 / 삭제 대신 보관 / 묶음마다 커밋)과
  옛 이름 ↔ 새 이름 대응표가 추가됨
- CS응대매뉴얼은 워드 파일이라 읽지 못해 이름 정리를 보류한 상태 (17장에서 해결)

## 쓰는 법

`part3-work-folder/`를 통째로 작업할 자리로 복사한다. 본문 16장에서 만든 Git 이력은 스냅샷에
담기지 않으므로, 이 폴더에서 시작한다면 `git init` 후 "스냅샷 시작 상태" 커밋 하나를
만들고 진행하면 된다. 이후 장의 커밋·되돌리기 실습은 전부 그 장 안에서 만드는
커밋으로 성립한다.
